# Architecture decision records

One file per decision, `NNNN-slug.md`, numbered in order of creation and never renumbered.

Each record has a status line (Proposed · Accepted · Superseded by NNNN) and four sections:
Context · Decision · Consequences · Revisit trigger.

This is a public repository: records are written in public-safe wording. Cross-repository
decisions are recorded in the private workspace and only referenced here by number.
